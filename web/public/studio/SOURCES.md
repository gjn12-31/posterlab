# Studio cover

`prism.webp` is a project-original render of ten curved proof sheets, produced with Mitsuba 3.9.1, NumPy and Pillow. The sheet geometry, print texture, studio environment and lighting were created procedurally for PosterLab. The scene mixes clear dielectric sheets, brushed aluminium and a printed cover. The thin mint highlights come from reflections of the virtual softboxes.

The final 1664 × 704 image uses 150 samples per pixel and render seed 294. It ships locally with the app. For the desktop design references, see the repository document `docs/desktop-direction.md`.
