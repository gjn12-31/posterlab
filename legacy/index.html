    关于这个版本

    这是 GitHub Pages 上的浏览器模板体验版。制作、排版检查和导出在你的设备上完成，活动内容不会发送给模型。公开示例来自清华大学交叉信息研究院，可能包含原文识别错误；请在发布活动前自行核对。

    完整的 Python 项目还包括模型接入、两轮生成、规则评测、人工复核和实验导出。API 配置保持留空，在线版的排版优化不代表 AI 实测结果。
