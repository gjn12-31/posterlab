# PosterLab print editions

The jellyfish, poppy, vinyl record and espresso stills were generated with OpenAI ImageGen for the PosterLab project on 2026-11-18. The original photographic-style compositions are packaged locally as WebP. Poster titles, activity information and editorial typography are rendered separately and remain editable. These images are distinct from the external NASA/JPL reference gallery.

Fold, Interval and Field Notes are original graphic compositions drawn for this project. The folded-paper geometry, interference curves and topographic illustration are stored as local WebP backgrounds. All type is added in the editor.
