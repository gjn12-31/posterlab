# 灵感首页与创作入口

首页参考 Suno 官网的暖色氛围、大字号标题、悬浮作品和居中输入框，保留 PosterLab 的对话与画布工作流。

## 操作流程

1. 首页输入创意，或点击咖啡市集、音乐现场、艺术展览填入一句话方向。
2. 点击「开始创作」，进入新的创作对话，输入内容已带入。此时尚未调用模型。
3. 在「创作偏好」中确认模型、尺寸与风格，补充标题、时间和地点，点击「生成海报」。
4. 也可在首页点击「帮我完善想法」，已有输入会带入需求助手。
5. 在「发现灵感」中筛选风格、搜索名称、点击海报放大；「用这个方向创作」带入独立的文字提示词。需要把【填写】占位内容替换为自己的信息。
6. 「我的作品」展示当前浏览器的最近对话；点击可恢复原画布、评测与版本记录。
7. 工作台右上角「发现灵感」或品牌名称可返回首页。`#studio` 可直接进入工作台，浏览器前进后退可切换页面。

## 网络样例

6 张 NASA/JPL Visions of the Future 系列海报已保存在 `web/public/inspiration/`，总计约 503 KB，不依赖第三方热链。画廊和详情页保留来源与署名，详见该目录的 `SOURCES.md`。它们标记为网络灵感，不与真实 AI 生成案例混淆。

## 交互与可访问性

- 画廊支持类别筛选、名称搜索、空结果清除。
- 原作详情使用原生 dialog，支持 Escape、焦点约束与关闭后焦点返回。
- 图片失败时提供明确占位，仍可查看文字方向。
- 首页输入保存到独立的本地草稿；保存失败会提示复制内容。
- 尊重系统减少动态效果偏好，也可手动关闭动效。
- 有任务处理中或待恢复时，禁止从首页发起新创作，但保留进入工作台的入口。
- GitHub Pages 保持明确的静态演示说明，不模拟实时生成。
