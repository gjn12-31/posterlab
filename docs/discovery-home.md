# PosterLab 使用说明

首页用悬浮玻璃印版介绍工作室。下滑或点击「探索工作台」进入互动演示，选择论文宣传或活动宣传可分别翻看图解和发布计划。页尾可打开设计样张或我的作品。在「海报设计室」可以自由生成一张海报，并按需要求对实际成图进行校对。「作品选集」可以逐个平台或画幅预览秋夜设计书展、PonderLM、M87 和街区咖啡日的真实成品，并下载 ZIP。选择书展或咖啡日后，点击「编辑这套海报」会在当前预览画幅打开独立副本，保留背景、可拖动图层及其余两个画幅。

## 从论文到四个平台的宣传材料

点击「导入论文 PDF」，选择带文本层的 PDF 或粘贴摘要。导入后显示论文识别卡。PDF.js 在浏览器读取前两页，分别提取摘要和引言。可直接生成，也可展开「查看或修改提取内容」校正文字、补充链接和署名。接通模型服务后，一次发送标题、署名和两段原文，生成英文 X 短帖串、小红书笔记、朋友圈分享语和公众号导读。每个平台都有对应尺寸的配图。点击「核对原句」可以查看生成时使用的完整摘要和引言，点「编辑」修改当前平台。小红书改写可选择从研究问题、方法动作或有依据的结果切入。用「选取论文插图」从 PDF 框选图片，或从本机上传有使用权的图片。整套 ZIP 包含四张配图、四份文案及出处。草稿可在「我的论文」找回。

点击「编辑图解长帖」，选择封面或内页即可改字、换引文并调整页序。卡片随当前论文保存，可以整组导出为 PNG，附带可复制的发布正文与逐卡出处。

## 从活动通知到宣传套装

点击「制作活动海报」，粘贴自己的活动通知。接通模型服务后点击「生成宣传套装」，即可获得邀请文案和推荐视觉。使用本地排版时点击「生成并预览」。三种画幅会按活动信息分别排版。并行智算云模式下还可点击「生成主视觉」。生成的配图会应用到当前活动的三种画幅，文字和二维码可继续单独调整。点击「改时间地点」更新整套并获得可直接转发的改期通知。点击「添加报名二维码」粘贴报名页地址。发布文案支持单独复制，整包下载包含三张图片、发布文案和可恢复的项目文件。生成的活动保存在当前浏览器的「我的作品」。

「编辑画布」可调整同一活动的排版、照片与文字，点左上角 PosterLab 回到制作台可继续更新活动。活动页也能直接切换视觉风格，单独下载某个画幅。

点击「打开活动发布计划」，依次检查活动预告、行前提醒和当天到场的文案与配图。可单独复制当前阶段，或将三项建议发布日期导入日历，再按日复制发布。整套活动 ZIP 附各阶段文案、配图清单及可用的日历文件。

## 看展与细读

从首页底部进入「灵感档案」。「展览现场」提供三个策展专题。进入展览后，下一件、缩略图目录或自动轮播都能切换作品。点击《神奈川冲浪里》的浪尖或富士山标记会直接放大该处。查看作品档案可读导览、作者、媒介和出处，并点击配色复制色值。

## 对照与收藏

在双联对照台左右各选一件作品。开启联动时，两图共享缩放比例和观察位置。放大后用鼠标、触屏拖动或方向键平移，点复位图标看全图。

点击书签收藏作品。高清看图里放大到需要的局部，点击「收藏当前局部」，会将取景和原作一起保存，同一件作品可以更新取景。在「我的收藏」添加笔记，再点「导出图集」。下载的 HTML 内嵌图像、取景与笔记，并保留馆方链接与图像使用信息。

## 动手创作

「设计样张」有七套可编辑样张。「试排我的标题」会同时更换样张标题。点任一样张即可打开画布，直接拖动文字、替换照片、添加活动信息或下载成品。三种画幅分别保存图层位置。PNG、SVG、活动包及可编辑项目备份均通过导出菜单获取。

模板项目保存在当前浏览器的 IndexedDB。归档收藏与观看笔记保存在当前站点的浏览器本地存储中。换设备时可携带导出的图集或项目备份。

## AI 辅助

接通服务后可以在编辑器中润色选中文案，也可以从首页底部的「海报设计室」进入独立工作台进行生成和评测。离线包内含本地排版助手与预录 AI 案例。

本机仍在运行旧版已授权后端时，可用 `PYTHONPATH=src python scripts/preview_outreach.py` 提供兼容入口，在另一个终端使用 `cd web && POSTERLAB_OUTREACH_PORT=8792 npm run dev`。兼容入口使用旧服务的 StepFun 3.7 Flash 对话接口撰写文案，避开海报字段编辑器的 2,048 token 上限，论文默认一次请求四个平台。当前版本的并行智算云和 StepFun 后端均自带原生论文接口。
