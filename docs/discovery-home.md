# 图像档案馆使用说明

## 看展与细读

「展览现场」提供三个策展专题。进入展览后，下一件、缩略图目录或自动轮播都能切换作品。点击《神奈川冲浪里》的浪尖或富士山标记会直接放大该处。查看作品档案可读导览、作者、媒介和出处，并点击配色复制色值。

## 对照与收藏

在双联对照台左右各选一件作品。开启联动时，两图共享缩放比例和观察位置。放大后用鼠标、触屏拖动或方向键平移，点复位图标看全图。

点击书签收藏作品。高清看图里放大到需要的局部，点击「收藏当前局部」，会将取景和原作一起保存，同一件作品可以更新取景。在「我的收藏」添加笔记，再点「导出图集」。下载的 HTML 内嵌图像、取景与笔记，并保留馆方链接与图像使用信息。

## 动手创作

「创作室」有七套可编辑样张。「试排我的标题」会同时更换样张标题。点任一样张即可打开画布，直接拖动文字、替换照片、添加活动信息或下载成品。三种画幅分别保存图层位置。PNG、SVG、活动包及可编辑项目备份均通过导出菜单获取。

模板项目保存在当前浏览器的 IndexedDB。归档收藏与观看笔记保存在当前站点的浏览器本地存储中。换设备时可携带导出的图集或项目备份。

## AI 辅助

接通服务后可以在编辑器中润色选中文案，也可以从创作室底部进入独立工作台进行生成和评测。离线包内含本地排版助手与预录 AI 案例。
