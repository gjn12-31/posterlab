# 活动海报排版选型

活动主办人输入一份通知后，三张图要能读清同一组事实，标题和场地要能拖动，改期后也要能再次导出。比较三个项目时，重点检查了它们的渲染介质、中文换行方式，以及接入后能否沿用已保存作品的图层坐标。

| 开源项目 | 官方文档及许可 | 在 PosterLab 中的适用范围 |
| --- | --- | --- |
| [foliojs/linebreak](https://github.com/foliojs/linebreak) | 按 Unicode UAX #14 给出合法断行位置；PDFKit 也将它用于文本换行。MIT。 | 已接入浏览器生成流程。画布按真实字体测量宽度，再从候选位置中选择断点。中英文标题、日期、场地和报名提示都使用这条路径。 |
| [vercel/satori](https://github.com/vercel/satori) | 根据 HTML/CSS 与输入字体生成 SVG。默认可把文字转成路径。MPL-2.0。 | 适合从网页模板生成分享卡。本项目已有可选中的 SVG 文字图层，迁移还需要处理字体和图层坐标的转换。 |
| [konvajs/konva](https://github.com/konvajs/konva) | 基于 Canvas 的交互图形场景，包含拖动、变换与事件分发。MIT。 | 适合以画布为中心新建编辑器。现有项目已经能把选区、拖动和导出映射到同一套 SVG 图层，本次主要缺口是窄栏文字排版。 |

## 实际接入

浏览器直接使用 npm 包 `linebreak@1.1.0`。库负责判断哪里可以断开；PosterLab 按当前字号和列宽逐行测量。两行标题会优先选兼顾中文词界和行宽均衡的合法断点。超过整栏宽度的单个长词才会拆到字素边界，在支持字素分段的浏览器中可以保留组合 emoji。

竖版海报用满幅摄影和独立的底部日程区；社交方图把活动标题跨栏放在上方，照片和时间地点分列下方；横幅把标题、时间和场地集中到左侧，给右侧照片保留足够面积。所有文字继续由活动数据和用户选定的图层样式驱动。带报名网址时给二维码留位。此前保存的活动作品沿用原有版式。

StepFun 生成的活动题签、选定的视觉风格和宣传文案可以进入同一份设计数据。坐标、文本断行以及生成 PNG 和 SVG 的工作由本地渲染器完成，样例和离线包也能完成这一流程。

## 验证与许可

浏览器测试覆盖七套风格与三个画幅的 21 种组合，测试输入含较长工作坊名称、场地、主办方、报名提示和二维码。另验证了拖动后的图层位置、独立 SVG 中的内嵌照片，以及 PNG 套装的实际下载。断行回归用例覆盖中文逗号、英文单词和组合 emoji。
