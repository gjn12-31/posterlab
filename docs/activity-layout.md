# 活动海报排版选型

活动主办人输入一份通知后，三张图要能读清同一组事实，标题和场地要能拖动，改期后也要能再次导出。比较三个项目时，重点检查了它们的渲染介质、中文换行方式，以及接入后能否沿用已保存作品的图层坐标。

| 开源项目 | 官方文档及许可 | 在 PosterLab 中的适用范围 |
| --- | --- | --- |
| [foliojs/linebreak](https://github.com/foliojs/linebreak) | 按 Unicode UAX #14 给出合法断行位置；PDFKit 也将它用于文本换行。MIT。 | 已接入浏览器生成流程。画布按真实字体测量宽度，再从候选位置中选择断点。中英文标题、日期、场地和报名提示都使用这条路径。 |
| [vercel/satori](https://github.com/vercel/satori) | 根据 HTML/CSS 与输入字体生成 SVG。默认可把文字转成路径。MPL-2.0。 | 适合从网页模板生成分享卡。本项目已有可选中的 SVG 文字图层，迁移还需要处理字体和图层坐标的转换。 |
| [konvajs/konva](https://github.com/konvajs/konva) | 基于 Canvas 的交互图形场景，包含拖动、变换与事件分发。MIT。 | 适合以画布为中心新建编辑器。现有项目已经能把选区、拖动和导出映射到同一套 SVG 图层，本次主要缺口是窄栏文字排版。 |

## 实际接入

浏览器直接使用 npm 包 `linebreak@1.1.0`。库负责判断哪里可以断开；PosterLab 按当前字号和列宽逐行测量。两行标题会优先选兼顾中文词界和行宽均衡的合法断点。超过整栏宽度的单个长词才会拆到字素边界，在支持字素分段的浏览器中可以保留组合 emoji。

竖版海报用满幅摄影和独立的底部日程区；社交方图把活动标题跨栏放在上方，照片和时间地点分列下方；横幅把标题、时间和场地集中到左侧，给右侧照片保留足够面积。所有文字继续由活动数据和用户选定的图层样式驱动。带报名网址时给二维码留位。此前保存的活动作品沿用原有版式。

模型生成的活动题签、选定的视觉风格和宣传文案可以进入同一份设计数据。坐标、文本断行以及生成 PNG 和 SVG 的工作由本地渲染器完成，样例和离线包也能完成这一流程。

## 自定义活动主视觉

保存活动简介后，点「生成主视觉」，并行智算云会根据标题、简介和所选风格生成一张背景图。编辑器把图片保存为项目素材，活动标题、时间与地点仍在独立图层中。服务端从 `PARATERA_API_KEY` 读取大模型平台的专用密钥，默认使用 `Doubao-Seedream-4.5`，可用 `PARATERA_IMAGE_MODEL` 更换型号。[图片生成接口](https://ai.paratera.com/document/llm/modalAbility/image)

2026 年 11 月 19 日，用同一份「秋夜设计书展」简介实测三款账户目录中的模型。耗时包括图片生成、下载及 WebP 转换。每个可用型号各出一张，再分别检查原图及居中裁切的竖版与横幅。

| 型号 | 本次结果 | 选型观察 |
| --- | --- | --- |
| Doubao-Seedream-4.5 | 8.49 秒，2048 × 2048 | 书脊、纸页和台灯侧光清楚，书本偏右，左下可叠浅色标题。横幅里保留了整本书，3∶4 居中裁切时最右侧书页贴边。 |
| Doubao-Seedream-4.0 | 7.37 秒，2048 × 2048 | 三种画幅均保留主体，但书页与灯罩的轮廓叠在一起。 |
| Doubao-Seedream-5.0-lite | 上游 HTTP 404 | 当次请求提示型号或端点不存在或无权访问。 |

两个成功结果均保留平台自带的「AI 生成」角标。生成端返回的图片链接只在服务端处理，临时下载失败后，在同一标签页重试或刷新后重试都会沿用原请求标识，仅重新取图。标签页按项目暂存请求标识及内容摘要值，生成并保存成功后清除。

### 可编辑的书展样例

「秋夜设计书展」使用虚构的活动通知。实际制作时，活动工作台向 `DeepSeek-V4-Pro-0813` 提交了一次文案请求，10.98 秒后返回邀请文案、英文题签及「深海微光」选版。主视觉复用了上表已经验收的 `Doubao-Seedream-4.5` 图片，在编辑画布的「主视觉 → 替换背景图片」中导入，保留平台角标。后续校对从本地缓存读取同一份模型文案。

竖版把标题拖到书本下方的深蓝区域，方形与横幅单独调整了地点字号。最终由活动工作台导出 1080 × 1440、1080 × 1080 和 1920 × 1080 三张 PNG，另附发布文案、可重新导入的项目文件和使用说明。[下载书展样例](../web/public/kits/bookfair.zip)

## 验证与许可

浏览器测试覆盖七套风格与三个画幅的 21 种组合，测试输入含较长工作坊名称、场地、主办方、报名提示和二维码。另验证了拖动后的图层位置、独立 SVG 中的内嵌照片，以及 PNG 套装的实际下载。断行回归用例覆盖中文逗号、英文单词和组合 emoji。
