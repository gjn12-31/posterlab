# 视觉评审标准 v1
四个维度分别为 readability / hierarchy / layout / style，整数 1–5，无法判断为 null。
- 可读性：1 关键信息无法辨认；3 基本可读、局部偏密；5 字号行距对比清楚。
- 信息层级：1 主次不明；3 大致明确；5 标题、事实、细节层级明确。
- 布局留白：1 严重拥挤或遮挡；3 可用但间距欠佳；5 对齐、间距协调。
- 风格：1 违背委托；3 基本一致；5 蓝白配色、字体和图片协调。
2/4 为相邻锚点之间。长文案是要求，不能仅因字多扣分。不合成百分制总分。
程序确定的交付、字号、素材错误不能被审美覆盖。图像和规则冲突需人工复核。
本轮尚未做真实评审模型校准。离线演示不产生虚构视觉分数。
