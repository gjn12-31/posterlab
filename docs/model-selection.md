# PosterLab 模型选型与成品核验

2026 年 11 月 19 日，使用并行智算云模型推理账户查询到 92 个模型 ID。以下请求通过 PosterLab 的服务端流程发送。生成质量根据实际返回的稿件、平台字数、最终画幅和活动事实核对。耗时为本轮单次观测。

## 论文宣传

使用 ICLR 2026 论文 PonderLM 的同一份摘要与引言节选，每个候选各请求一次。检查了方法描述、架构名称、九项基准的比较方向，以及“十倍训练数据”属于哪一组。X 加权长度按 twitter-text 计算。中文长度计入标点及拉丁字母，测量对象是编辑处理前的模型稿。[会议论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/94572a66c6b0710c5263f15d8ef6b463-Abstract-Conference.html)

| 候选模型 | 四个平台 | 耗时 | X 三条帖的加权长度 | 小红书首行 / 朋友圈字符数 |
| --- | --- | ---: | --- | --- |
| Kimi-K3.1-Pro | 全部返回 | 31.97 秒 | 150 / 233 / 214 | 42 / 151 |
| DeepSeek-V4.1-Flash-1017 | 全部返回 | 49.62 秒 | 198 / 198 / 202 | 34 / 216 |
| DeepSeek-V4-Pro-0813 | 全部返回 | 95.68 秒 | 216 / 240 / 142 | 53 / 219 |
| Qwen3.8-Max | 上游 HTTP 504 | 180.32 秒 | — | — |

选用 **Kimi-K3.1-Pro**。它在公众号稿中区分了跨架构的测试范围与 Pythia 的具体比较，并正确说明 PonderPythia-2.8B 在九项测试的平均表现超过 Pythia-6.9B、接近 12B。另两个成功候选也保留了比较方向，Flash 写的“多 10 倍”容易产生歧义。三款的小红书第一行都偏长，Kimi 的公众号稿还带有 Markdown 小标题。发布流程增加了短标题约束与纯文本整理。按新规则用 Kimi 再跑同一输入，四稿用时 33.64 秒。小红书标题为「不生成词元，模型怎么思考」（12 字符），三条 X 帖的加权长度为 216、262 和 203，公众号稿中没有残留的 Markdown 小标题标记。Qwen 当次没有产出可评价的稿件。

PDF.js 在浏览器读取前两页，界面默认展示文件及识别状态。点击生成后才将标题、署名、摘要和引言交给模型。四个平台共享这一次输入，作者可以保留证据、修改单个平台、选取论文插图并导出。[开源方案选择](outreach-research.md) · [20 篇 ICLR 2026 小红书笔记](iclr-rednote-study.md)

正式网页还做了一次从 PDF 到 ZIP 的单请求验证。直接上传 PonderLM 会刊 PDF 时，两页中可读的摘要、引言分别为 1,262 和 3,576 个字符（修复图表残片前）。模型保留了实验比较方向。随后根据论文核对题名和九位作者，选取四条完整引文，并附上依据论文图 2 重绘的示意图。四份发布稿正文保持模型原稿，仅更新公众号页尾的书目。首页作品选集可打开这次实测的最终稿，预览图文和整套下载读取同一个 ZIP。

在处理该 PDF 的过程中还修复了第一页混合字号导致的标题截断。修复后的导入器在会刊版和 arXiv 版 PonderLM、引力波并合论文及《Attention Is All You Need》上均还原了正确题名。作者不能确认时留空，可在「核对原句」中补齐，草稿、出处及导出的书目同步更新。此次还根据 PDF 字形和行位置清除了误入摘要的图表刻度、上标脚注及跨页页眉。修复后同一 PDF 的摘要为 1,215 字符、引言 2,884 字符，四条默认引文均可在原文核对区逐字查到。其中包含九项基准和 PonderPythia 与 TinyLlama 的完整比较句。

再用 LIGO 的双黑洞并合论文测试默认流程。直接上传 PDF，一次 Kimi 请求用时 40.12 秒，自动识别完整英文题名和 DOI。四份成稿与公开论文比对，35–250 Hz 的频率范围、信噪比 24、距离及黑洞质量的不对称误差均保留。四条 X 帖（含 DOI）的加权长度为 192、205、255、27，小红书标题为「双黑洞并合信号如何被确认」。文案保持自动生成结果，配图使用应用默认构图。校样时调整了方图、竖图的装饰区，重新导出后标题和图形间距分别为 57 和 75 像素，四份文案保持原样。该 PDF 的部分公式字符在文本层有编码异常，作者栏留空，核对精细单位仍需参考原 PDF。[LIGO 论文原文](https://doi.org/10.1103/PhysRevLett.116.061102)

## 活动邀请与三种画幅

**DeepSeek-V4-Pro-0813** 用 22.40 秒将街区咖啡手冲交换日写成邀请，保留无需预约、自带杯子和交换咖啡豆。另一份秋夜设计书展简报用时 10.98 秒，稿中保留裸脊线装、锁线胶装和现场翻阅。日期、时间和场地使用活动字段统一排版。两场活动均为虚构测试简报。

选用 **Doubao-Seedream-4.5**。服务只向图像模型请求背景，把可编辑标题、时间地点和二维码留在画布。首页的书展案例沿用这张真实主视觉和正式接口生成的邀请，在网页画布调整标题位置和字号后导出。ZIP 内含 1080 × 1440 竖版、1080 × 1080 方图、1920 × 1080 横幅、发布文案、使用说明和可编辑项目。平台角标保留在成品中。[活动版式实测](activity-layout.md)

## 海报设计室与成图校对

自由设计通过模型生成 HTML/CSS/SVG。后端校验活动事实、渲染真实 PNG，按需将成图发送给视觉模型。测试采用另一份书展简报，时间与场地均以该份输入为准。

**DeepSeek-V4-Pro-0813** 首轮 3 分 14 秒返回设计；本次处理真实输出时修复了代码围栏解析和静态 SVG 阴影兼容。原始回复可在本地恢复，无需再次生成设计。1080 × 1440 成图包含活动名、2026-12-05、17:00–21:00 及城市艺术中心·一层展厅。**Qwen3.7-Plus** 对这张 PNG 进行六维评测，按现有权重得到 91.7/100，并指出底部左对齐信息与上方居中构图可进一步协调。评分来自模型，实际检查另行核对了可见字段和图像尺寸。

同一简报在 GLM-5.3 上的首轮耗时 7 分 39 秒，16,384 个输出 token 中有 16,361 个用于思考，海报正文为空。旧流程发出的一次纠错在连接中断后结束，当次没有 PNG 可以比较。当前流程遇到整轮用尽输出额度且没有海报正文时直接返回原因，避免再次自动请求。

## 在工作台选择模型

论文导入和活动宣传页提供「模型设置」。可以分别指定研读、排版、撰稿、改写、主视觉和成图审阅使用的模型。海报设计室在「创作偏好」中分别设置对话、设计与评测。选择按当前浏览器的工作区保存，留在「服务默认」即可沿用服务端配置。

| 并行智算任务 | 可选模型 | 核验依据 |
| --- | --- | --- |
| 研读、文案与活动策划 | Kimi-K3.1-Pro、DeepSeek-V4-Pro-0813、DeepSeek-V4.1-Flash-1017 | 三者均在同一论文输入上交付四平台文本，见上文对照。 |
| 概念配图与活动主视觉 | Doubao-Seedream-4.5、Doubao-Seedream-4.0 | 两者均通过图片生成接口返回 2048 × 2048 像素的活动主视觉。 |
| 成图审阅 | Qwen3.7-Plus、GLM-4.6V | Qwen 通过实际海报评测。GLM 通过相同图像消息协议的能力抽检，在合成三色图上以 JSON 正确返回蓝、黄、红的从左到右顺序。 |

原创建议中的 Qwen3.7-Plus 可读取上一版成图。纯文本设计模型使用已有源码和修改说明。自定义服务端默认型号按相应任务加入清单。失败会显示上游或校验错误；已支付且仍可下载的论文配图沿用原请求的模型和取图回执，无需重新生成。并行智算接口没有提供实结金额时，工作台保留预算预留记录，实际费用以平台账单为准。
