# Lightfield Studio · 实施记录

实施日期：2026-10-24。基于仓库 `c5dbe20398de89ac7922aa08e62268cf7238b15c`，分支 `feat/lightfield-studio`。

## 本轮已实现

- React / TypeScript / Vite 工作台，动态光场背景、浮动海报、金属环、玻璃浮层、悬浮组件与转场；三级动效和系统减少动态偏好。
- 内容、风格、素材三面板；六套模板；3:4、1:1、16:9 三种画幅共享内容。
- 灵感实验室：用当前活动并排生成六套实际模板预览，点击应用。
- 标题字号、对齐、品牌色与名称；图片 / Logo 上传和移除；真实报名二维码。
- 活动通知本地提取；AI 提取、改写的服务端接入；应用前逐字段差异预览。
- AI 字段锁定，人工导入时明确选择是否覆盖锁定信息。异步 AI 返回时如作品已变化，会拒绝应用陈旧建议。
- IndexedDB 自动保存、作品搜索与复制、撤销 / 重做、20个历史快照与恢复。
- JSON 备份 / 导入，旧版同源 localStorage 迁移，CSV 最多30条批量建项目。
- 高清 PNG、内嵌字体的 SVG、三尺寸 PNG + 项目 JSON + 发布文案 ZIP。
- 必填字段、合法日期 / URL、文本超长 / 溢出、品牌对比度、二维码密度检查。错误阻止导出，警告保留人工判断。
- FastAPI 本地服务；StepFun 文本适配；SQLite 持久预算、事务预留、幂等请求、最多2个进行中请求、超时不自动重发。
- 保留旧版静态编辑器和原有 Python / Streamlit 研究功能；修复原 provider 传输异常可能重复发送付费请求的问题。

## 工程与接口

前端源代码在 `web/`，构建到 `site/`。统一 SVG 布局函数用于预览和导出，避免 Canvas 和网页两套排版互相偏离。编辑粒度为活动字段、品牌与模板属性，尚未提供任意图层拖拽。字体随项目提供并保留许可，两个 WOFF2 约22MB；首次加载会有等待，SVG 为保持中文字形内嵌完整字体，因此文件较大。

`GET /api/status` 只读取配置和账本，不调用模型。`POST /api/assist` 仅在点击 AI 动作后调用固定的 `https://api.stepfun.com/v1/chat/completions`，模型 `step-3.5-flash`。服务读取 `STEP_API_KEY`，浏览器不接收密钥。

| 能力 | 外部 API | 状态 |
|---|---|---|
| 通知理解、文案改写 | StepFun 文本接口 | 模拟响应测试及一次真实浏览器改写通过 |
| 图像生成、修图 | 需后续另选供应商 | StepFun 原图像接口已退役，本版不接入 |
| 模板预览、排版、二维码、导出 | 无 | 本地可用 |
| 品牌、项目、版本 | 无 | 当前浏览器 IndexedDB；JSON 可迁移 |
| 团队、云同步、登录、评论 | 未来数据库与鉴权服务 | 本轮未实现 |

预算默认累计 ¥5，每次调用先预留 ¥0.10。已知 token 用量按本轮核验价估算，最终费用以供应商账单为准；没有 usage、网络中断或服务端5xx时保留预留。请求结果缓存用于幂等返回；账本不存密钥或原始通知，但成功建议可能含活动文字。账本属于本机数据，请按个人数据管理。

未知状态与崩溃留下的 pending 不会自动清除或重试。核对供应商账单后由维护者修正 SQLite 对应记录的 state / reserved / spent，保留审计备份。不要通过删除账本绕过预算。后续应增加可审计的对账界面和按日预算。

服务默认只监听 127.0.0.1，校验 Host / Origin / Fetch Metadata，限制 JSON 大小，不提供公网多用户鉴权。GitHub Pages 只部署前端，AI 服务不会随 Pages 发布。

## 验证

- Python：41项通过（模型协议、预算并发、锁定、恶意结果、幂等、超时恢复，以及原有渲染 / 工作流 / Streamlit 回归）；旧版浏览器端到端脚本本轮未运行。
- TypeScript 类型检查、Vite 生产构建、8项 Vitest 数据边界测试通过。
- 实际浏览器：编辑、通知提取与人工覆盖锁定、风格应用、撤销 / 重做、重新加载恢复、图片 / Logo、三尺寸 ZIP 下载与画幅尺寸、390px 手机布局，以及版本恢复、CSV 两条批量导入、SVG 下载解析。
- ZIP 下载中三张 PNG 的尺寸为1080×1440、1080×1080、1920×1080，已查看导出图像；二维码来自指定链接，不是装饰图形。
- 已完成一次真实 StepFun 编辑：将活动标题改为指定文案，锁定日期 / 地点等保持不变，浏览器展示差异后应用成功。该次估算费用为 ¥0.0012782，实际以供应商账单为准。其余边界测试使用 MockTransport；单次成功不代表所有提示词的文案质量。
- 当前运行服务的密钥仅存在进程环境中，未写入代码、配置或交付包；服务重启后需通过本地环境配置。
