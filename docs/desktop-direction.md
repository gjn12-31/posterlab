# 桌面视觉参考

## Lusion

Lusion 首页先用一句话说明工作室做什么，首屏保留联系入口和滚动提示。后面的作品目录把项目名称和设计、开发、3D 等工作范围放在一起。PosterLab 借用这种阅读顺序：先让来访者看懂可以制作什么，输入和导入紧跟在标题旁边，结果区再展开各个发布渠道。核对内容包括官方首页文案、界面元素和三个 canvas 节点。[Lusion 首页](https://lusion.co/)

## 宇树 G1

G1 产品页把大幅机器人影像与产品名、用途、价格和视频入口放进同一个镜头。继续向下，关节灵活性、学习能力和灵巧手分别获得独立的演示区域，详细参数留给需要查阅的人。PosterLab 的桌面构图据此把主对象放在画面一侧，另一侧留给最常用的操作。活动和论文各有自己的工作区，用户可以在结果旁继续编辑或下载。[宇树 G1 中文产品页](https://www.unitree.com/cn/g1)

## Igloo

Igloo 的官方分享图只用一座灰白冰屋、雪地、粗字标和小号说明，就建立了可辨认的品牌形象。站点前端的作品对象对应具名项目，并配有滚动发现和点击探索的操作提示。PosterLab 的主对象由十张具有厚度与弯曲弧线的印样构成，薄荷色高光来自模拟棚灯在页边的反射。首屏使用预渲染图，文件读入与编辑操作可独立运行。Igloo 动态场景在本次无头浏览器中未完整载入，观察依据是站方发布的主图、官方文案与前端资源。[Igloo 首页](https://www.igloo.inc/) · [官方分享图](https://www.igloo.inc/assets/images/social.jpg)

这三个站点用于研究信息层级与主视觉构图。PosterLab 使用自行建模的印样，模型、灯光、印刷纹理均为本项目制作。
