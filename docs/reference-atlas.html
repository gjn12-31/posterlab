从看见局部，到读懂作品

一张图让人停下来之后，访客可能想知道画的是哪里、作者如何用色，或者把它和另一张图放在一起。我们从八个参考站点研究这些动作如何发生，以及哪一步适合进入创作工具。

八个站点的浏览方式

数字敦煌

首页先按洞窟与壁画提供入口，再把窟号、年代和壁面位置写在作品旁。“莫高窟第 23 窟主室北壁”本身就能帮助读者定位。专题里的局部也值得这样标注，让人知道当前看到整件作品的哪一处。

首页与经典壁画 · 第 23 窟北壁

书格

首页明确注明背景图是画作局部，补充馆藏线索与相关链接。《江枫秋艇图卷》条目从江面、霜林讲到山石皴法和点叶。局部裁切承担了一个具体的阅读任务，值得给它配一句指向可见细节的说明，再让读者展开全图。

首页背景图说明 · 江枫秋艇图卷

IGNANT

Design 频道用一篇家具设计访谈开场，标题、地点和导言先建立主题，下方的最新文章继续标明家具、室内或产品等领域。首页的专题可以用一个明确的观察问题串起几件作品，作品总览则留给想自由浏览的访客。

Design 频道

Siteinspire

作品目录把风格、网站类型、主题和平台拆成独立入口，列表还把站点与设计者关联起来。访客仅仅记得“木版画”或某位作者时，也应该能用这些已知线索找到作品。适合小型馆藏的起点是少量有内容的筛选项。

网站与设计者目录 · 编辑精选

Mobbin

首页分别展示单个界面、完整流程、动画和界面元素等浏览对象，让人先选自己想观察的尺度。我们可以把同样的清晰度用在作品上，分别以“看全图”“放大细节”“加入对照”说明操作结果。

产品与资料库介绍

Studio Dumbar

Work 目录用项目名称配简短用途说明。打开 DEMO 2025 后，独立项目页解释动态设计节与扭曲地球图形之间的关系。每件展品也可以有一个稳定入口，让人能够把正在读的那件作品直接发给别人。

项目目录 · DEMO 2025 项目

Packaging of the World

站点同时提供策展人精选和按材质、国家、年份查找的目录。帮助页还说明怎样找设计者以及怎样询问授权。作品档案同样应在赏析旁注明作者、藏馆、图像出处与使用条件，让观众能核对来源。

项目与策展目录 · 检索与署名说明

Fonts In Use

它用真实应用实例组织字体资料，主题、载体和字体名称分别可查，高级检索允许组合条件。收藏之后的下一步可以是把两件作品并排，看相近颜色在不同媒介、不同画幅里的作用。

字体应用档案 · 组合检索

PosterLab 的设计取舍

  1. 首页先给一个值得看的专题。 由一件作品的局部和一个观察方向开场。进入专题后，应能看到关联作品及它们被放在一起的理由。
  2. 看图时，让作品身份与操作一起可见。 载明作者、年代、媒介和出处。放大查看细节后能回到全图，收藏后能在自己的收藏中找回同一件作品。
  3. 给收藏一个用途。 并排查看两件作品时，保留各自的标题和署名，方便直接比较构图、笔触与配色。
  4. 把创作留给可实际编辑的设计。 馆藏和参考作品提供赏析、收藏与来源；原创设计的编辑入口直达可拖动图层的画布。AI 在作者选中内容后按需辅助。

核对方式：直接读取了数字敦煌、书格、IGNANT、Mobbin、Studio Dumbar 与 Fonts In Use 的官方公开页面。本机访问 Siteinspire 和 Packaging of the World 首页时遇到浏览器验证，这两站的栏目与操作名称依据其官方页面的公开索引正文核对。研究范围为公开资料，未进入付费账户。文中的并排对照、编辑权限划分是本项目的产品设计取舍。
